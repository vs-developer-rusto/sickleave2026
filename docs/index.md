# Больничный 2026

Ориентировочный расчёт пособия по временной нетрудоспособности за ~30 секунд: грязными, НДФЛ и на руки.

Без аккаунта, без облака. Android-приложение для RuStore.

## Возможности

- сумма грязными и на руки;
- НДФЛ 13% / 15% с учётом дохода с начала года;
- средний дневной заработок (СДЗ) за 2 года (÷730);
- процент оплаты по страховому стажу: 60% / 80% / 100%;
- пол МРОТ при СДЗ ниже расчёта от МРОТ 2026;
- потолок предельных баз страховых взносов 2024–2025;
- история последних расчётов на устройстве.

## Важно

Это ориентир, не расчёт бухгалтера и не юридическая консультация.
